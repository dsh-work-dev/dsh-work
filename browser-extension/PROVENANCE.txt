playwright/ contains the seven modules carried by the validated E-53/R-69 fork:
relayConnection, connectedTabGroup, cdpRelayV2, browserModel, manualPromise,
protocol and log. Imports are relative; unused LongStandingScope is omitted.
The debug package is replaced by a console error sink, not another dependency.
The debugger close/attach race fix from upstream c2298ad is retained.

DSH Work changes: NativePort transport; Go-generated session route and selected
instance ownership; reject foreign debugger/tab operations; independent local
release on disconnect; session-title truncation and unique colors; serialized
group creation with late-close ungrouping. Recovery queries only recorded owned
tab IDs in storage.session, not every group by title. Debug logging is off.
No research inspection operation, A/B route restriction or connection page.

Build: install the existing frontend/package-lock.json toolchain (npm ci in
frontend), then node browser-extension/compile.mjs to refresh embedded routes.js.
node browser-extension/build.mjs --out <owned-or-empty-directory> recompiles the
same source into an unpacked extension. No cache paths are overridden.
The host embeds the checked-in routes.js plus known runtime/license files.
MCP remains pinned at 0.0.83 / SDK 1.32.2 in automation's existing lockfile.
